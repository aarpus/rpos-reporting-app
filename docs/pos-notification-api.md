# AcutePOS notification API (C#)

The POS sends events to `POST /api/pos/notification-events`. The reporting app stores the inbox item and sends Web Push; the POS never calls a browser push provider directly.

## Credentials

Generate the server encryption key once and keep it in both `.env.local` and the Cloudflare Worker secrets:

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

After applying the database migration, provision a credential and save the returned secret in the matching POS installation. Administrators can do this from Store Management (`/admin/stores`): creating a store opens the credential step, and each store row has a POS credential action. The same result is available from the command line:

```powershell
npm run pos:credential -- create DT01
```

The plaintext secret is printed only during creation. Rotate by creating a new credential, deploying it to the POS, and then running:

```powershell
npm run pos:credential -- deactivate DT01 OLD_KEY_ID
```

## C# signing example

The timestamp is Unix seconds. Sign the exact UTF-8 bytes sent in the HTTP body; reserializing after signing invalidates the signature.

Interop test vector:

- Store: `DT01`
- Key ID: `pos-test`
- Timestamp: `1790706600`
- Secret: `AQIDBAUGBwgJCgsMDQ4PEBESExQVFhcYGRobHB0eHyA=`
- Expected signature: `aSlHcqyjKNSiNUNoKj7L+skIMyjzIXNlpr56tFmhFEE=`

```csharp
using System.Net.Http.Headers;
using System.Security.Cryptography;
using System.Text;
using System.Text.Json;

var storeCode = "DT01";
var keyId = "pos-issued-key-id";
var secret = Convert.FromBase64String("pos-issued-secret");
var timestamp = DateTimeOffset.UtcNow.ToUnixTimeSeconds().ToString();
var payload = new {
    eventId = Guid.NewGuid().ToString(),
    type = "SHIFT_END",
    occurredAt = DateTimeOffset.UtcNow,
    data = new {
        shiftId = "shift-123",
        shiftNumber = "12",
        endedAt = DateTimeOffset.UtcNow
    }
};

var bodyBytes = JsonSerializer.SerializeToUtf8Bytes(payload);
var canonicalPrefix = Encoding.UTF8.GetBytes($"{storeCode}\n{keyId}\n{timestamp}\n");
var canonical = new byte[canonicalPrefix.Length + bodyBytes.Length];
Buffer.BlockCopy(canonicalPrefix, 0, canonical, 0, canonicalPrefix.Length);
Buffer.BlockCopy(bodyBytes, 0, canonical, canonicalPrefix.Length, bodyBytes.Length);
var signature = Convert.ToBase64String(HMACSHA256.HashData(secret, canonical));

using var request = new HttpRequestMessage(HttpMethod.Post, "https://YOUR_HOST/api/pos/notification-events");
request.Headers.Add("X-Store-Code", storeCode);
request.Headers.Add("X-POS-Key-Id", keyId);
request.Headers.Add("X-POS-Timestamp", timestamp);
request.Headers.Add("X-POS-Signature", signature);
request.Content = new ByteArrayContent(bodyBytes);
request.Content.Headers.ContentType = new MediaTypeHeaderValue("application/json");
using var response = await httpClient.SendAsync(request);
```

Retry network errors and `5xx` responses with the same `eventId`. Do not retry `4xx`. A `202` means the inbox event was accepted; it is not a device-delivery receipt. A duplicate retry returns `200` with `status: "duplicate"`.

## Event bodies

Replace each placeholder before serializing the request. Every `eventId` must be
unique per store. Retrying the same event must reuse its original `eventId`.

### Shift end

`shiftNumber` is the ID used by the reporting dashboard's shift-detail route.
`shiftId` remains the POS system's stable internal identifier.

```json
{
  "eventId": "{{eventId}}",
  "type": "SHIFT_END",
  "occurredAt": "{{now}}",
  "data": {
    "shiftId": "shift-114",
    "shiftNumber": "4",
    "endedAt": "{{now}}"
  }
}
```

Generated view: `/report/shift-report/4`

### Day end

```json
{
  "eventId": "{{eventId}}",
  "type": "DAY_END",
  "occurredAt": "{{now}}",
  "data": {
    "businessDate": "2026-10-01",
    "reportId": "4",
    "closedAt": "{{now}}"
  }
}
```

Generated view: `/report/day-end-report/4`

### Low stock

```json
{
  "eventId": "{{eventId}}",
  "type": "LOW_STOCK",
  "occurredAt": "{{now}}",
  "data": {
    "productId": "product-501",
    "sku": "SKU-501",
    "productName": "House Margarita Mix",
    "currentQuantity": 3,
    "threshold": 5
  }
}
```

Generated view: `/` (dashboard inventory overview)

### Void or refund

Use `VOID` or `REFUND` for `action`.

```json
{
  "eventId": "{{eventId}}",
  "type": "VOID_REFUND",
  "occurredAt": "{{now}}",
  "data": {
    "transactionId": "RPOSD1042883",
    "action": "REFUND",
    "amount": 14.71,
    "currency": "USD",
    "performedAt": "{{now}}"
  }
}
```

Generated view: `/report/transaction-detail/RPOSD1042883`

All date-time values must be ISO 8601 values with an offset, for example
`2026-10-01T12:30:00Z`. Numeric fields such as `amount`, `currentQuantity`, and
`threshold` must be JSON numbers, not quoted strings. Titles, messages, and
navigation targets are generated by the reporting server in
`src/lib/pos-events.ts`.
