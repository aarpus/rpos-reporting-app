## Partially implemented

Home dashboard and old home services use fixture values. The retail home page renders a fixture layout (KPI tiles, sales detail, sales trend, invoices, and payment reminders) with the application theme; those figures are sample preview values, not live retail totals. The retail sidebar keeps Dashboard in the main menu and lists the quick reports; Shift End Report, Day-End Report, Week End Report, Month End Report, Credit Card Transaction, Monthly Sales and Tax, and Invoice Report open. The Reports link stays on the mobile sidebar and bottom navigation. The retail report index lists the same quick reports. Shift End Report uses the shared retail date filter and datatable, which other retail reports can reuse. On small screens that datatable switches to stacked cards so every field stays readable without horizontal scrolling; from the md breakpoint up it keeps the full table. A date search reads `tbl_shift_end_report` for the signed-in retail store. The overlap uses the store timezone: the start date is on or before the filter end, and the end date is on or after the filter start. An open shift with no end stays in range when its start is on or before the filter end. The single-date calendar heading opens a month list and a year list (2000 through five years ahead) so the month and year can be chosen directly. Reset clears both date filters. The result table stays visible and shows an empty row when no shifts match. The eye action opens that stored shift: employee header, sales, taxes, sales breakdown, miscellaneous, terminal cash status, and terminal cash transfer. Export prints that page so it can be saved as a PDF. Day-End Report uses that same date filter and datatable with sample July 2025 batches. Its columns are batch number, batch start, batch end, status, and view. The eye opens a sample day-end detail with the shift-detail chrome: back, store code, title bar, and export. The body uses the preview department sales, sales totals, cash status, tender breakdown, paid in and paid out, tax, cash acceptor, employee clock, miscellaneous, and promotion figures. Export prints that page so it can be saved as a PDF. Week End Report uses Month and Week filters only (current and past months; no year dropdown). Searching July Week-2 2025 shows the sample store heading, week-range title bar, department sales, sales summary, sales breakdown, and tax detail; other weeks show an empty message. Export prints that report so it can be saved as a PDF. Month End Report uses Year (current and previous year only) and Month filters; the current year lists months through the current month, and the previous year lists all months. Searching July 2025 shows the sample month-end department, summary, sales breakdown, and tax figures; other months show an empty message. Export prints that report so it can be saved as a PDF. Credit Card Transaction uses the shared retail date filter and datatable with sample Apr–Aug 2025 card rows. When the search returns rows, View Details opens the full card transaction report with type, terminal, brand, and external-pay summaries; Export prints that page so it can be saved as a PDF. Monthly Sales and Tax uses the shared Year/Month filter from Month End Report. Searching July 2025 shows the sample daily sales and tax table with GiftCard and Total rows; other months show an empty message. Export prints that report so it can be saved as a PDF. Transaction Journal Report uses the shared retail date filter plus Transaction#. Searching a 2025 range shows sample July journal rows with station, totals, cashier, and View. View opens `/report/transaction-journal/view/{id}` with line items, credit-card detail, and paid-by breakdown; list filters stay in the URL for Back. When rows match, Print Transaction Detail opens `/report/transaction-journal/print-detail` with grouped line items, per-transaction subtotals, and Print; Print Summary prints the list header and datatable (all rows, no View action column). A funnel button is reserved for later filters. Invoice Report uses the shared retail date filter plus amount from/to, invoice type, supplier name, and supplier invoice number. Searching July 2025 shows sample supplier invoices with View, Profit Margin, Cost Variance, Qty Variance, and View Log action icons. Applied filters are stored in the list URL query string and carried into action routes so Back restores the same search. View opens `/report/invoice-report/view/{id}/{type}` with invoice meta, product lines, totals, and export. Profit Margin opens `/report/invoice-report/profit-margin/{id}/{type}` with cost/retail/profit columns and summary totals. Cost Variance opens `/report/invoice-report/cost-variance/{id}/{type}` with new/previous cost, difference, average cost, and retail columns. Qty Variance opens `/report/invoice-report/qty-variance/{id}/{type}` with ordered/received quantities, difference, and stock-on-hand. View Log opens a large Invoice log modal with Date and Log columns for that invoice. Restaurant shift/day/week/year reports render fixtures; month report renders zero/empty shells. Employee clock report filters fixture sessions and calculates display totals, without a live read/write backend. Event links to shift/day reports consequently do not guarantee matching real records. Notification API supports cursor pages but the UI does not consume later pages.
